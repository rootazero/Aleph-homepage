# 执行 Harness

`AgentHarness` 驱动所有 Gateway 聊天请求的 **Think → Act** 循环。它由编排器构造，并接收预解析的依赖项（`SessionService`、`ToolService`、`Sandbox`、`AiProvider`）。

**位置**：`src/harness/`

> **迁移完成**：旧版 `src/agent_loop/` 目录已在第 7 阶段（2026-04-21）删除。所有智能体执行 —— 包括 `SubagentTool` —— 现在均通过 Orchestrator → Harness 路由。

## 状态机

Harness 使用 `TurnState` 枚举来跟踪当前回合的状态：

```
┌─────────┐
│ PREPARE │
└────┬────┘
     │ budget computed
     ▼
┌─────────┐     ┌─────────┐     ┌─────────┐
│  THINK  │ ──▶ │ RESOLVE │ ──▶ │   ACT   │
└─────────┘     └────┬────┘     └────┬────┘
                     │               │
                     │ EndTurn       │ tools complete
                     │ no_action     │
                     ▼               ▼
               ┌─────────┐     ┌─────────┐
               │FINALIZE │     │FINALIZE │
               └────┬────┘     └────┬────┘
                    │               │
                    ▼               ▼
              ContinueLoop      ExitLoop
```

`TurnAdvance` 枚举控制循环推进：

| Variant | Meaning |
|---------|---------|
| `Next(TurnState)` | Advance to the next state |
| `ContinueLoop` | Restart with a new turn |
| `ExitLoop(decision)` | Terminate loop with final decision |
| `Cancelled` | Cancelled by abort token |

## 守卫

安全检查在每个循环迭代前运行。位于 `src/harness/guards.rs`。

| Guard | Purpose |
|-------|---------|
| `MaxIterationsGuard` | Prevent infinite loops |
| `TokenBudgetGuard` | Enforce token limits |
| `TimeoutGuard` | Enforce time limits |
| `ToolRateLimitGuard` | Prevent tool spam |
| `ErrorAccumulatorGuard` | Stop on repeated errors |

```rust
pub trait LoopGuard: Send + Sync {
    fn check(&self, state: &LoopState) -> GuardResult;
    fn name(&self) -> &str;
}

pub enum GuardResult {
    Continue,
    Warn(String),
    Stop(String),
}
```

## 睡眠抑制器

每个 Think→Act 回合会获取一个 `IOPMAssertion`，类型为 `PreventUserIdleSystemSleep`，原因字符串为 `"Aleph agent loop"`。该断言由一个 RAII `InhibitorGuard` 持有，其 `Drop` 实现在回合返回的瞬间释放。长时间运行的智能体回合不再会被 macOS 将主机置于睡眠状态而静默中断。

该守卫在 `src/harness/agent.rs` 中的 `run_turn` 开始时获取，并在函数返回时自动释放，无论成功、返回错误或被取消。

要验证回合进行中是否有断言处于活动状态：

```bash
pmset -g assertions | grep "Aleph agent loop"
```

断言在回合完成的瞬间从列表中消失。

实现文件：
- `PowerCapability` trait: `desktop/shared/src/traits/power.rs`
- macOS IOPMAssertion FFI: `desktop/macos/src/sleep_inhibitor.rs`
- Agent loop wiring: `src/harness/agent.rs::run_turn`
