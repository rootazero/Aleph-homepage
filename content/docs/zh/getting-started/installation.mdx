本指南涵盖了在你的系统上安装 Aleph。

## 前置条件

- **Rust 1.92+** - 从源代码构建需要（参见 `Cargo.toml` 中的 `rust-version`）
- **just** - 命令运行器（`cargo install just`）
- **npm** - 用于构建 WASM 面板 UI
- **wasm-bindgen** - WASM JS 绑定（`cargo install wasm-bindgen-cli`）
- **macOS 14+**、**Linux** 或 **Windows** - 主要支持的平台
- **SQLite** - 通过 `rusqlite` 捆绑（无需单独安装）

### 平台特定要求

**macOS：**
- Xcode 命令行工具
- Swift 工具链（用于桌面桥接）

**Linux：**
- `build-essential` 或等效工具
- `pkg-config`
- `libssl-dev`

**Windows：**
- Visual Studio 生成工具
- `windows-sys` 功能由 Cargo 自动处理

## 安装方法

### 使用 Just（推荐）

Aleph 包含一个带有常见开发任务的 `justfile`：

```bash
# 验证所有构建依赖已安装
just deps

# 以开发模式运行服务器（重建 WASM）
just dev

# 构建发布二进制文件
just build

# 运行测试
just test
```

### 从源代码

```bash
# 克隆仓库
git clone https://github.com/rootazero/Aleph.git
cd Aleph

# 验证依赖
just deps

# 以开发模式运行
just dev

# 或构建发布二进制文件
just build
```

发布二进制文件将位于 `target/release/aleph-server`。

### 验证构建

```bash
# 快速编译检查
just check

# 运行核心测试
just test

# 检查所有 crate，包括桌面端
just check-desktop
```

## 目录结构

Aleph 在 `~/.aleph/` 创建以下目录：

| 路径 | 用途 |
|------|---------|
| `~/.aleph/` | 主配置目录 |
| `~/.aleph/aleph.toml` | 主配置文件 |
| `~/.aleph/logs/` | 服务器日志 |
| `~/.aleph/skills/` | 用户安装的 skill |
| `~/.aleph/plugins/` | 扩展 |
