---

## memory_search

搜索知识库获取相关事实。

```
<builtin_tool>memory_search</builtin_tool>
<parameter name="query">我们决定了用什么数据库？</parameter>
<parameter name="limit">5</parameter>
```

**参数：**
- `query`（必需）— 搜索查询
- `limit`（可选）— 最大结果数，默认 5
- `agent_id`（可选）— 目标代理命名空间
- `mode`（可选）— `context` | `tools` | `hybrid`，默认 `hybrid`

**返回：** 带分数的 `MemoryFact` 排序列表。

---

## memory_reflect

**Spec 2.** 从记忆中综合出连贯的答案，而非返回原始事实。

```
<builtin_tool>memory_reflect</builtin_tool>
<parameter name="query">总结我们了解到的用户需求</parameter>
<parameter name="depth">comprehensive</parameter>
```

**参数：**
- `query`（必需）— 要回答的问题
- `depth`（可选）— `brief` | `standard` | `comprehensive`，默认 `standard`
- `agent_id`（可选）— 目标代理命名空间

**返回：** 带引用来源的综合答案。

---

## session_search

**Spec B.** 跨会话对话记录搜索。

```
<builtin_tool>session_search</builtin_tool>
<parameter name="query">我们什么时候讨论过认证？</parameter>
<parameter name="limit">5</parameter>
```

**参数：**
- `query`（必需）— 搜索查询
- `limit`（可选）— 返回的最大会话数，默认 5
- `summarise`（可选）— `true` | `false`，默认 `true`

**返回：** 匹配会话 + AI 生成摘要（如果 `summarise=true`）。

---

## remember

**Spec A.** 将事实固定到精选热记忆。

```
<builtin_tool>remember</builtin_tool>
<parameter name="content">用户偏好所有应用使用深色模式</parameter>
<parameter name="priority">8</parameter>
```

**参数：**
- `content`（必需）— 要记住的事实
- `priority`（可选）— 1-10，越高越重要，默认 5
- `category`（可选）— 如 `preference`、`fact`、`warning`

**返回：** 带事实 ID 的确认。

**注意：** 精选记忆是**冻结快照**。变更需要显式重新策划。

---

## forget

从记忆中移除事实。

```
<builtin_tool>forget</builtin_tool>
<parameter name="query">用户的旧邮箱地址</parameter>
```

**参数：**
- `query`（必需）— 要移除的事实描述
- `confirm`（可选）— `true` | `false`，默认 `false`

**返回：** 候选事实列表 + 确认提示（如果 `confirm=false`）。

---

## memory_status

检查记忆系统健康和统计信息。

```
<builtin_tool>memory_status</builtin_tool>
```

**返回：**
- 笔记总数
- 原始记忆数（未处理）
- 索引健康状态（FTS + 向量）
- 上次梦境运行时间戳
- 精选记忆数量

## 方法对比

| 方法 | 何时使用 | 返回 |
|---|---|---|
| `memory_search` | 需要特定事实 | 排序的事实 |
| `memory_reflect` | 需要综合/答案 | 连贯答案 + 来源 |
| `session_search` | 查找过往对话 | 会话 + 摘要 |
| `remember` | 关键事实绝不能遗漏 | 确认 |
| `forget` | 移除过时信息 | 确认 |
| `memory_status` | 调试记忆问题 | 统计信息 |

---

## 错误处理

所有记忆方法返回结构化错误：

| 错误 | 含义 |
|---|---|
| `MemoryNotFound` | 无匹配事实/会话 |
| `IndexCorrupted` | SQLite 索引需要重建 |
| `QuotaExceeded` | Token 预算耗尽 |
| `LockTimeout` | 跨进程争用 (Spec C) |
