团队方法管理多代理团队——具有定义的角色、通信模式和协调策略的协作任务 AI 代理组。

## 方法

### teams.list

列出所有配置的团队。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "teams.list",
  "params": {}
}
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "teams": [
      {
        "id": "team-1",
        "name": "Code Review Team",
        "agents": ["reviewer", "tester", "documenter"],
        "status": "idle"
      }
    ]
  }
}
```

### teams.create

创建新的团队配置。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "teams.create",
  "params": {
    "name": "Bug Fix Squad",
    "agents": [
      {
        "role": "debugger",
        "model": "claude-sonnet",
        "system_prompt": "You are a debugging specialist."
      },
      {
        "role": "fixer",
        "model": "claude-sonnet",
        "system_prompt": "You implement fixes."
      }
    ],
    "coordination": "sequential"
  }
}
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "team": {
      "id": "team-2",
      "name": "Bug Fix Squad",
      "agents": ["debugger", "fixer"],
      "status": "idle"
    }
  }
}
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----------|------|----------|-------------|
| `name` | string | 是 | 团队名称 |
| `agents` | object[] | 是 | 代理配置，包含 `role`、`model`、`system_prompt` |
| `coordination` | string | 否 | 协调模式：`"sequential"`、`"parallel"`、`"hierarchical"` |

### teams.get

获取团队详情。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "teams.get",
  "params": {
    "team_id": "team-1"
  }
}
```

### teams.run

使用团队执行任务。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 4,
  "method": "teams.run",
  "params": {
    "team_id": "team-1",
    "task": "Review this pull request for security issues",
    "context": {
      "pr_url": "https://github.com/org/repo/pull/123"
    }
  }
}
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 4,
  "result": {
    "run_id": "run-team-1",
    "status": "running"
  }
}
```

### teams.delete

删除团队配置。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 5,
  "method": "teams.delete",
  "params": {
    "team_id": "team-2"
  }
}
```

## 协调模式

| 模式 | 说明 |
|------|-------------|
| `sequential` | 代理一个接一个地运行，将输出向前传递 |
| `parallel` | 代理同时运行，结果在末尾合并 |
| `hierarchical` | 领导代理将子任务委托给工作代理 |
