群聊方法管理多方对话——在共享聊天上下文中涉及多个 AI 代理和/或人类参与者的对话。

## 方法

### group_chat.list

列出所有活动的群聊。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "group_chat.list",
  "params": {}
}
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "chats": [
      {
        "id": "gc-1",
        "name": "Project Planning",
        "participants": ["user", "planner", "coder"],
        "message_count": 42,
        "created_at": "2024-01-15T10:30:00Z"
      }
    ]
  }
}
```

### group_chat.create

创建新的群聊。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "group_chat.create",
  "params": {
    "name": "Code Review",
    "participants": ["reviewer", "tester"]
  }
}
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "chat": {
      "id": "gc-2",
      "name": "Code Review",
      "participants": ["user", "reviewer", "tester"],
      "created_at": "2024-01-15T10:30:00Z"
    }
  }
}
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----------|------|----------|-------------|
| `name` | string | 是 | 聊天名称 |
| `participants` | string[] | 是 | 要包含的代理角色（用户始终包含） |

### group_chat.send

向群聊发送消息。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "group_chat.send",
  "params": {
    "chat_id": "gc-1",
    "message": "What do you think about this approach?",
    "sender": "user"
  }
}
```

**响应：**
```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "result": {
    "message_id": "msg-1",
    "responses": [
      {
        "from": "planner",
        "message": "This looks solid. I suggest..."
      },
      {
        "from": "coder",
        "message": "Implementation-wise, we could..."
      }
    ]
  }
}
```

### group_chat.history

获取群聊的消息历史。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 4,
  "method": "group_chat.history",
  "params": {
    "chat_id": "gc-1",
    "limit": 50
  }
}
```

### group_chat.add_participant

向群聊添加参与者。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 5,
  "method": "group_chat.add_participant",
  "params": {
    "chat_id": "gc-1",
    "participant": "documenter"
  }
}
```

### group_chat.remove_participant

从群聊中移除参与者。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 6,
  "method": "group_chat.remove_participant",
  "params": {
    "chat_id": "gc-1",
    "participant": "tester"
  }
}
```

### group_chat.delete

删除群聊。

**请求：**
```json
{
  "jsonrpc": "2.0",
  "id": 7,
  "method": "group_chat.delete",
  "params": {
    "chat_id": "gc-2"
  }
}
```
